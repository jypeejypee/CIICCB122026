# Java Practice (CIICC)

My lessons and exercises from learning Java fundamentals at CIICC.

## Lessons

| Folder | Topics |
|---|---|
| `chapter1/` | Primitive vs. reference types, constructors, instance initializers |
| `chapter2/` | Operators, equality (`==` vs. `.equals()`), `if` / `switch`, loops |
| `chapter3/` | Strings and their methods |
| `task/` | Practice tasks (Task 1–6), e.g. looping through arrays with `break` and conditions |

## Run a file

Each file has its own `main` method. From the repo folder:

```bash
javac chapter3/StringLesson.java
java chapter3.StringLesson
```
